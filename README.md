# Attendly

### Attendance & Leave Management System

Attendly is a modern, local-first **Attendance & Leave Management System** built with **Flutter Web**.

The system is initially designed to work completely offline using **IndexedDB** for local data persistence, while keeping the architecture ready for future backend integration and data synchronization.

---

## 🚀 Project Overview

Attendly is designed to help organizations manage:

- Employee attendance
- Check-in / Check-out
- Working hours
- Late arrivals
- Employee shifts
- Leave requests
- Leave balances
- Leave approvals
- Official holidays
- Attendance reports
- Leave reports
- Employee management

The initial MVP is completely local and does not require an internet connection or backend server.

---

## ✨ Features

### 👤 Employee

Employees can:

- Login using Employee Code and PIN
- View their dashboard
- Check in
- Check out
- View today's attendance
- View attendance history
- View working hours
- View late minutes
- View assigned shift
- View leave balances
- Submit leave requests
- View leave request history

---

### 👑 Admin

Admins can:

- Login to the Admin Dashboard
- View attendance overview
- Manage employees
- Manage departments
- Manage shifts
- View employee attendance
- Manage leave requests
- Approve leave requests
- Reject leave requests
- View leave balances
- Manage leave types
- Configure leave policies
- Manage official holidays
- Generate attendance reports
- Generate leave reports

---

## 🕐 Attendance Management

Attendly supports:

- Check-in
- Check-out
- Late calculation
- Working hours calculation
- Missing check-out detection
- Daily attendance status
- Attendance history
